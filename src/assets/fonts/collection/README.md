# Collection fonts

Twenty-three film title faces: each catalog entry uses a distinct font family, selected in `src/data/collectionArt.ts`. Source Sans 3 (medium 500) is the one supporting text face. The three existing title faces and their licenses remain in the parent directory. All new files are self-hosted Latin WOFF2 subsets from the official Google Fonts CSS service, retrieved 2026-10-26. No runtime request to Google is made.
