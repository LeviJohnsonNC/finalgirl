# Carnival module artwork

Five original generated illustrations, 1536 × 1024, encoded to WebP at quality 88. Owner photos IMG_9338–IMG_9343 supply factual references; the UI uses original illustrations, never photographs of cards. Artwork is evocative, not a board diagram or exact placement reference.

- banner: wide header crop; attractions independent of Killer.
- board-traps: 3 columns × 2 rows. Columns blades, rope, acid. Top unplaced, bottom placed.
- item-traps: 3 columns × 2 rows. Columns cobra, bear, gas. Top dormant, bottom encountered.
- companions: 3 columns × 2 rows. Sibling, Fiancé, Werewolf; Zappo, Golf Cart, Forest of Horrors.
- events: 2 columns × 2 rows. Clowns, Animal Panic; dangerous traps, mirrors.

SVG atlas rectangles inset four pixels to keep panel boundaries outside crops. State labels remain readable independently of color, and ended/unrecorded actor/Event imagery is muted. Original generated PNGs remain outside the repository.
