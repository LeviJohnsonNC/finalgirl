# Wide photographic Play artwork

Generated 2026-10-26 for Levi's explicit request for wider photorealistic Power, Finale, Minor Power and Sacred-space views. These are original thematic UI photographs, not official card scans, rule evidence, new canonical character facts or recorded narrative/death events. Existing supplied identity pictures and original artwork remain intact.

Use physically believable practical costumes/materials and real locations, available light, candid consumer 35mm color-negative capture in the 1980s, restrained color/grain and coherent shadows. Avoid painting, digital/CGI surfaces, excessive grading and decorative vintage damage. Never use grain/blur to disguise illustration. Titles, health, Epic and all state information are accessible HTML. Photos remain stable through health changes.

Each killer source is a 2-column by 5-row contact sheet. Sacred sources are 2 columns by 4 rows. Derivatives use a 3px safety inset, center crop to native approximately 16:9, WebP quality 88, no stretching or upscaling. Budget: 160KiB per photo. Source PNGs remain in image-generation output, not in the build.
