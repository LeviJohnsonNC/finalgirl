# Intruder photography

These are original practical-costume images generated individually with the built-in image generation tool. The existing group casting photograph was the identity reference. The original generated file, original digest, derivative path, crop dimensions, and byte budget can be audited through `manifest.json` and `npm run check:assets`.

The Play banner uses a separately composed trio shot. Three 360×540 portraits fill the roster. Each of the 18 individual card and Terror scenes uses an 864×486 crop. The nine Power, Finale and Minor Power scenes also have 288×162 choice thumbnails. The banner and larger stills stay below 160 KiB, with thumbnails below 35 KiB.

Common direction: Original physically real 1980s consumer color-negative 35mm photo for horror game UI. Candid, unposed, practical costume textures and convincing human proportions, restrained grain, natural exposure, motivated practical light, no CGI, illustration, colored gels, gore, text, borders or logos. The supplied existing casting photo is identity and wardrobe reference only, use a new moment and composition. Mask details and silhouette must match that photo precisely.
