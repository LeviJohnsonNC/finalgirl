# Evomorph Play photographs

Generated 2026-10-29 for Levi's requested Play polish. Twelve independent original landscape photographs: Hatchling and Youngling, three Minor Dark Powers, four Dark Powers (including Epic Razor Tail), and three Finales. The existing Adult portrait is retained.

Art direction: physically tangible burgundy/ivory creature materials, coherent available utility light, candid consumer-camera 1980s color-negative photography, restrained grain. The existing Adult reference is `src/assets/characters/ai/evomorph.png`; the approved Inkanyamba photo and supplied Evolution reference were inspected. Early-stage fine detail is a decorative interpretation of the limited larval/compact silhouettes, not newly verified canonical anatomy.

Each generated source is a separate native landscape, not a contact-sheet crop. `manifest.json` records its source filename, native dimensions, derivative dimensions, compression quality, byte size and SHA-256. Derivatives are centered 1280×720 WebP, never upscaled, each at most 160 KiB. Raw generation originals remain outside the app bundle. No card text, stage labels, health or interactive state is baked into images.
