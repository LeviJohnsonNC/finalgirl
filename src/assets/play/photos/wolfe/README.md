# Wolfe Asylum photography

Original generated stills from the built-in image tool. User photos establish room and component details. The visual brief follows the approved candid 1980s 35mm material and lighting standard. Grain is restrained and faces, clothing, old steel, plaster and linoleum remain visibly photographic. HTML supplies all labels and state.

The banner is 1360 × 907. Original state images are 764 × 508 WebP. Most state images are independent rectangles in 2 × 2 production sheets (1536 × 1024). The extraction crops two pixels inside every edge and never scales a state above its native cell. The inactive Common Room is a reference edit of the active photograph. The photo set occupies about 1.2 MB.
