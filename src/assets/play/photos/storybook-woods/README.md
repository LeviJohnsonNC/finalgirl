# Storybook Woods photography

Original scenes made with the built-in image generator using the approved candid 1980s color-film direction. The existing Storybook Woods casting photo informed the village and materials in the river banner. The crossing pairs use the same landmark and camera position. Saved and killed portraits use the matching in-play person reference. Aftermath portraits are non-graphic.

[Manifest](manifest.json) records each independent source image, prompt, reference, digest, native size, export size, crop and surface. The Play panorama is a 1500 × 500 WebP. All 21 other images are 1280 × 720 WebP. Each export is at most 160 KiB and cropped without stretching or upscaling. The Full Moon uses three different landscapes and the header for the neutral, unlocated preview. The shallow death tiles use vertical focus at 30% for Clearing, 14% for Meadow, 20% for Glen and 100% for Getting Treats for Grandmother. The main Play header uses 56%. Art is illustrative of the chosen state and establishes no gameplay facts.

The original generated frames remain separate from repository derivatives. The source board and cards supplied game facts. Runtime images contain no photographed game components.
