# Marrek Warehouse photographs

33 individually generated original landscapes, produced with the built-in image-generation tool on November 1, 2026. These are atmospheric UI photographs, not publisher card scans, new canonical role identities or evidence that a game event occurred. Retain the existing location selection portrait and selected-image preferences; this import adds a separate Play header.

The realism reference was the approved Inkanyamba consumer-camera photograph. Direction: candid 1980s 35mm, tangible shipping warehouse materials, ordinary available light, restrained grain, no illustration/CGI, forced teal-orange grading, printed UI or mandatory Tormentor. The Pit stays a normal working-floor area. Special people have original adult casting; the chosen Final Girl retains her separate identity.

`manifest.json` records each native source filename, SHA-256, exact generation/edit prompt, identity reference where used, actual native/derivative dimensions, focal position, file bytes and derivative hashes. Sources are independent 1536×1024 landscapes; none is an enlarged contact-sheet cell. Existing source originals are preserved with the generation outputs. Runtime photographs are proportionally downsampled WebP, 1279–1280×853 (≤160 KiB), with 399–400×267 thumbnails (≤35 KiB). Header hero is `src/assets/play/banners/marrek.webp`; its thumbnail stays here. There are 66 runtime derivatives, all checked by `npm run check:assets`.
