# Bloodlust photographs

Refreshed 2026-10-28 at Levi’s request for a slower, more varied escalation and a truly disturbing moon face in the final two images. Eleven separate photographs retain the cabin/dock/canoe scene and fixed camera. Terror builds through clouds, advancing mist, extinguished cabin lights, rough water and the growing moon; dominant crimson arrives late rather than midway. Only stages 9–10 have faces.

These images represent the Killer’s Bloodlust across all killers. There are no people, Final Girl, identifiable Killer, weapons, bodies or casualties. The cabin/lake/weather are a decorative metaphor, not facts about the selected Location or session. UI art never enters narrative context. No changes to track numbers, observation history, overflow, unknown state, mappings or game rules.
