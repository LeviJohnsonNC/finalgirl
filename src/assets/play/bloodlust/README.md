# Bloodlust photographs

Refreshed 2026-10-27 from Levi’s three supplied lakeside references. Eleven separate photographs preserve one fixed scene: moonlit lake, opposite-shore timber cabin, left dock, pine forest and empty foreground canoe. Stages 0–4 move from cold blue anticipation through pink/copper light and gathering crimson clouds; stage 5 is deep red dread; stages 6–10 intensify the moon, storm arcs, mist and reflections toward the red climax. Final ordering was reviewed visually rather than trusting generation request numbers.

These images represent the Killer’s Bloodlust across all killers. There are no people, Final Girl, identifiable Killer, weapons, bodies or casualties. The cabin/lake/weather are a decorative metaphor, not facts about the selected Location or session. UI art never enters narrative context. No changes to track numbers, observation history, overflow, unknown state, mappings or game rules.
