# Bloodlust photographs

Generated 2026-10-27 for Levi's approved tracker-art plan. Eleven individual photographs show one neutral pale stone surface progressing from clean and undisturbed at stage 0 through droplets, trickles, spreading stains and pooled dark red stage liquid at stage 10. No named killer, weapon, victim, text or game component appears. These are decorative UI motifs, never evidence of an injury, casualty, object or location in a generated story.

The clean source is the material/camera reference for stages 1–9. Physically coherent available light, tactile materials and restrained consumer 35mm rendering carry the realism. No decorative grain/dust/filter pass was added. Each original square source is 1254×1254; derivatives are 768×768 WebP, quality 70, method 6, metadata stripped, without upscaling or semantic edits. Per-image budget: 160KiB. Only the current picture is rendered; no atlas or image bytes are embedded in edge functions.
