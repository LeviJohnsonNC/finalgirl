- `doctor.webp`: 1024×1536 with alpha, one scarred yellow-clothed Dream Doctor and three-tined pitchfork. The renderer fits the complete cutout inside one quadrant. It mounts the cutout only when that quadrant is actually exposed; no hidden variant image URL or card identity is rendered.

SVG viewboxes use a four-pixel safety inset, with stable catalog mapping before alphabetical display sorting.

The cover, captions, progress, focus and actions are HTML/SVG UI, not generated writing. The common room plus cutout avoid accidental identity clues in the empty portions of a concealed card. Actual card visibility and attack detection share the same tested half-card geometry.
