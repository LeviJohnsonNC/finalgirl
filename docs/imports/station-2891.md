# Station 2891 location import plan

**Status:** Implemented in draft PRs, November 11, 2026. Standard Series 2 location for the existing *Panic at Station 2891* film (`s2-panic-station-2891`). Proposed location module ID `station-2891`. Audited current `main` at `8338d47`, which includes The Organism import from PR #204. The companion [Organism record](the-organism.md) covers the independent killer import.

## Scope and current support

Station 2891 already has casting and Collection entries, location and loader artwork, and a partial shared Play catalog. The catalog has all eight Terror names with three effects, all ten Event names with one effect, generic room suggestions and a Frostbite death mechanism. There is no registered Station location Play panel or searchable Station rules module. Extend those existing surfaces and keep Station selectable with any killer. The Organism retains ownership of its testing, assimilation, mutations and four Test Kit Items. Correct film detail text that currently conflates the location with The Organism, calls a setup “A New Stew,” and turns the Lab accident into automatic victim death. Use region-neutral visual prose where existing lore mixes Arctic and Antarctic geography, while retaining printed names on the helicopter route.

Use the repo’s [module standard](https://github.com/LeviJohnsonNC/finalgirl/blob/main/docs/MODULE_STANDARD.md), [control contracts](https://github.com/LeviJohnsonNC/finalgirl/blob/main/docs/module-controls.md) and [import playbook](https://github.com/LeviJohnsonNC/finalgirl/blob/main/docs/MODULE_IMPORT_PLAYBOOK.md). The approved Sacred Groves captures govern presentation. USS Konrad’s current controls provide the precedent for equipment, people and ongoing Events. Creech Manor’s helicopter shows how to record a linked rescue, but its one-use state is specific to Creech Manor. Falconwood is the precedent for piloting the main interaction in the real app before producing the full art set.

**Mixed killers.** The Organism’s Exposed Victims cannot board or become Station Special Victims. A SAFE test can make a surviving victim eligible under normal rules. Assimilation is a mutation and does not create a human death. Respect killer restrictions in the death flow, including Slayer’s dimension and existing explicit exceptions, without assigning a location hazard to a killer. Creech Manor’s Carolyn-specific link is not a generic Station passenger type. Any unevidenced cross-film passenger interaction stays with the physical adjudication, with no inferred outcome or new linked-owner rule.
